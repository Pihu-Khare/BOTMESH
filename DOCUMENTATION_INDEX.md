## 🚀 Quick Start (TL;DR)

```bash
# 1. Setup
cp .env.example .env
# Edit .env with your settings

# 2. Install
npm install

# 3. Database
createdb botmesh_db
psql botmesh_db < database/schema.sql

# 4. Run
npm start

# 5. Access
http://localhost:5000
```

For details, see [SETUP.md](SETUP.md)
