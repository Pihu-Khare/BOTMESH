## 🚀 Getting Started (5 Minutes)

### Step 1: Configure
```bash
cp .env.example .env
# Edit .env with your credentials
```

### Step 2: Setup Database
```bash
createdb botmesh_db
psql botmesh_db < database/schema.sql
```

### Step 3: Install
```bash
npm install
```

### Step 4: Run
```bash
npm start
```

### Step 5: Access
```
http://localhost:5000
```

| Issue | Solution |
|-------|----------|

| Invalid Token | Expired (24h default), try logging in again |
| AI API Error | Check Google API key, verify API enabled |
| Port 5000 In Use | Kill process: `taskkill /PID [pid] /F` |
